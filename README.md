# 🌐 Palani Padayathirai Website

Official website for **Palani Padayathirai**, a spiritual pilgrimage companion platform dedicated to supporting devotees traveling to Arulmigu Dhandayuthapani Swamy Temple, Palani.

The website serves as the official public platform for application information, legal policies, support, account management, and community resources.

---

## 📖 Overview

The Palani Padayathirai website is designed to provide pilgrims, visitors, and users with access to important information about the platform and its services.

The website includes:

* Official product information
* Privacy Policy
* Terms & Conditions
* Community Guidelines
* Account Deletion Requests
* Contact & Support
* Frequently Asked Questions

# 🚀 Getting Started

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Start Production Server

```bash
npm start
```
